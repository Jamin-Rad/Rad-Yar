## Follow-up repair evidence

The existing thorax routes `/thorax/tuberkulose-muster`, `/thorax/roentgen-thorax-systematik`, and `/thorax/fremdkoerperaspiration` now pass explicit route-specific DE/EN/FA take-home rules to the shared shell. `ClinicalPatternDiagram.jsx` now provides explicit labels for TB, pneumonia/HRCT, pancreas, foreign-body, chest-X-ray, and bowel schematics in all three supported languages. The isolated `scripts/check-thorax-route-fallbacks.cjs` checks that the three route summaries are present and that selected diagram-label groups have locale entries; this is structural only, not semantic translation or medical review. JSX transform and whitespace checks passed. No build or browser verification was run.

Broader PDF topic coverage and line-by-line source alignment remain incomplete. Clinical claims still need claim-level review; diagnostic-image rights remain unresolved for patient images, which are not copied into these authored lessons. Global curriculum/quiz/flashcard integration is pending central coordination. Browser UX and coordinated application build remain unverified.
