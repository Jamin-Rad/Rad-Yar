# Dorsal wrist anatomy, extensor compartments and De Quervain — MSK.pdf pp.40–43

## Scope and learning plan

- Source: `C:/Users/Drham/OneDrive/Desktop/Lerncore/MSK.pdf`, physical pages 40–43; printed folios 39–42.
- Intended audience: radiology learners familiar with axial MRI anatomy.
- Learning outcome: orient dorsal carpal bones and joint lines from the source figure, map the six wrist extensor compartments on an axial MRI, localize the first compartment, and describe the PDF's De Quervain MRI pattern.
- Existing route: `/msk/hand/de-quervain` (`de-quervain`). Added focused standalone orientation route `/msk/hand/strecksehnenfaecher` for the curriculum topic `sehnenpathologien-hand`; central curriculum/assessment links remain for coordinator integration.
- Exact chapter outline for the separate orientation route:
  1. **Welche Knochen und Gelenklinien sehe ich dorsal? / Which bones and joint lines do I see dorsally?** Read the labelled source diagram from metacarpals through the two carpal rows to radius/ulna, then trace its named joint lines.
  2. **Wo liegen die Fächer im axialen Bild? / Where are the compartments on an axial image?** Orient radius, ulna, Lister tubercle and the numbered compartments using the source MRI.
  3. **Welche Sehnen verlaufen durch die sechs Fächer? / Which tendons pass through the six compartments?** Compare all six tendon groups and one source-listed landmark each; include the VI/ECU retrieval check here.
  4. **Vier Orientierungspunkte / Four orientation points.** Consolidate the spatial map without introducing new anatomy.
- De Quervain route retains its existing clinical/MRI sequence; a PDF p.43 real MRI pair is added to the findings section and linked to the compartment orientation lesson.
