## Independent review and correction

The independent reviewer found a nomenclature mismatch between classic Tile basic type B and the AO/OTA 2018 61B subgroups shown in the source illustration. The lesson now labels the row as Tile basic type B and explicitly explains that AO/OTA 2018 61B1 lacks rotational instability while 61B2 is rotationally unstable. This distinction is linked to the relevant AO Surgery Reference definitions. The reviewer also confirmed that the L5 caveat remains appropriately qualified and the supplied image is anatomical, not diagnostic.

The assessment is now registered under the exact curriculum topic in the global DE/EN/FA question bank, with two four-option MCQs and two flashcards. Lesson header actions link to those exact resources. Browser/device review and clinician sign-off are still pending; these changes do not constitute clinical release approval.
