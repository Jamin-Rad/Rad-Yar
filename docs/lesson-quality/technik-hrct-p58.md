# HRCT technique — Technik.pdf p.58 (printed p.57)

Bounded addendum for exact curriculum ID `hrct-technik` in `/technik/grundlagen#ct`. The physical PDF page was rendered and visually inspected; it contains no diagnostic case image. It teaches acquisition technique and supplementary maneuvers, not HRCT pattern interpretation.

## Source map and disposition

| Source point | Lesson disposition |
|---|---|
| HRCT as a technique for detailed lung-parenchyma assessment, especially the secondary lobule | Stated in the lead; no broader disease-pattern lesson duplicated |
| Thin collimation 0.5–1.5 mm reduces partial-volume effects | Taught with the source range explicitly qualified as source-specific, not a universal scanner protocol; note trade-off with noise |
| Sharp/bone kernel for edge detail | Taught as a high-frequency-kernel trade-off, with noise and task/system dependence |
| Small lung-limited FOV with high matrix reduces pixel size | Taught as a sampling/geometry relationship; no claim that matrix alone sets system resolution |
| Expiratory CT for air trapping; example bronchiolitis obliterans; affected regions remain relatively dark during expiration | Taught as an adjunct and finding clue, not a stand-alone diagnosis |
| Prone CT to distinguish dependent opacity from early fibrosis | Taught as an adjunct: dependent opacity tends to decrease while persistent change remains; contextual interpretation retained |
| Indications listed: ILD, bronchiectasis, emphysema, mosaic pattern/air trapping | Kept as source-listed application scope without adding diagnostic pattern criteria; pattern interpretation remains in existing Thorax lessons |
| No contrast evaluation and no vascular diagnosis | Stated as scope boundary for lung-parenchymal HRCT; a separate protocol may be needed for a different question |
| Source dose comparison: HRCT 1–2 mSv vs routine chest CT 5–7 mSv | Deferred: these are not taught as current/universal values; dose varies by scanner, patient, scan coverage and protocol |
