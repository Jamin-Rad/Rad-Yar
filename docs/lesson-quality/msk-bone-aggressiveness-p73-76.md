# Focal bone-lesion aggressiveness — source ledger

Date: updated 2026-10-22. Existing route `/msk/tumoren/knochenzeichen`; no duplicate route. Source: user-supplied `MSK.pdf`, physical PDF pp.73–76 / printed folios 72–75. Page images and extracted text were both inspected. The source contains radiographic examples, but contributor, acquisition and case provenance are not available; this focused audit does not reuse them as diagnostic teaching cases.

## Learning path

1. Recognise periosteal response patterns and interpret named tumour associations as examples, not exclusive signs.
2. Relate mineralised matrix to possible tissue origin without treating a pattern as a diagnosis.
3. Combine lesion margin/Lodwick pattern with cortex and soft-tissue extent, then state limits of the inference.
4. Apply the pattern to an embedded text self-check that asks for appropriate next interpretation, not a tumour label.

## Terminology and validation scope

Language units were authored in parallel in German, English and Persian. High-risk distinctions: “typical/classic” is not “specific”; periosteal response estimates aggressiveness, not histology; smooth cortex is not a universal benign rule; endosteal scalloping is a warning association, not a diagnosis. The existing lesson self-check remains text-only and checks this distinction.

Source verification: periosteal geometry and matrix morphology checked against González-Huete et al., *Radiographic Evaluation of Bone Tumors*, RadioGraphics 2023, and Alencar et al., *Periosteum: An imaging review*, 2020; Lodwick subtypes/descriptor limitations checked against Benndorf et al., *The Lodwick classification for grading growth rate of lytic bone tumors*, Skeletal Radiology 2022. The source PDF’s perpendicular-spicule/Sunburst wording is explicitly qualified against current terminology. No diagnostic source frame was selected because provenance cannot be established.
