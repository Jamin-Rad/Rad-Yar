The broader lesson material on Doppler, shunt patterns and HHT is supplemental to this one-page source and must retain its separately cited evidence. Current EASL vascular-liver guidance distinguishes arterioportal fistula (early portal-tree enhancement) from hepatic arteriovenous fistula (early hepatic-vein enhancement); the lesson therefore describes these as distinct intrahepatic shunt types and clarifies that a portal-to-hepatic-vein portosystemic shunt is not an AV fistula. A professional ultrasound standard supports the distinct normal Doppler patterns now stated in the lesson: relatively continuous hepatopetal portal flow versus cardiac-phasic, usually triphasic hepatic-vein flow. The global AVM Doppler MCQ now tests only the normal hepatic-vein waveform and explains the portal-vein distinction in feedback; the table header distinguishes modality/vessel from expected appearance or flow. The prior general statement “no relevant wash-out” has been removed because it conflicts with the supplied page. Resolving whether the PDF describes an AVM-associated focal lesion or shunt-related perfusion requires the original case citation and phase/structure mapping, followed by specialist review.
