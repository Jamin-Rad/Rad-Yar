# Knochenmetastasen — source and authoring ledger

Date: 2026-10-20. Bounded lesson for the existing curriculum ID `knochenmetastasen`, route `/msk/tumoren/knochenmetastasen`. Source: user-provided `MSK.pdf`, physical PDF pp. 102–103, printed pp. 101–102. Both extracted text and rendered page images were reviewed. The lesson is a focused imaging orientation, not a staging or treatment guide.

## Learning path

1. Classify the bone response as lytic, sclerotic, or mixed without inferring the primary tumour from the pattern alone.
2. Match radiograph, CT, MRI, and scintigraphy to the imaging question and understand important limits.
3. Treat the pedicle sign and Mirels score as contextual clues/tools rather than definitive diagnoses or automatic treatment instructions.
4. Apply the distinction in a short self-check.
