# German lesson illustrations

Generated with the built-in ImageGen tool (not the CLI). The six original PNGs were visually reviewed, then resized to 900 × 600 WebP for the existing lesson header. Each prepared lesson has a distinct image; the homepage keeps its neighborhood illustration. No generation service is called when a lesson opens.

Assets are in `public/andarun/deutsch/lessons/`:

Shared prompt: Use case illustration-story. One finished landscape 3:2 website lesson header illustration. Warm editorial gouache and watercolor with fine organic detail, warm ivory paper (#f6f4ed), forest green and terracotta accents, natural light. Compact scene for a sophisticated adult German language-learning publication. Softly feathered painted edges fading into ivory, generous breathing space, readable at 300px width. No text, lettering, numerals, logos, watermark, webpage or mockup.

Imported lessons can supply their own prepared local file through `illustration`, for example `/andarun/deutsch/lessons/meine-lektion.webp`. Lessons without an explicit asset use a relevant topic illustration.
